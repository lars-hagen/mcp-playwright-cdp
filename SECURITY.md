# Security Policy

## Supported versions

Security fixes are provided for the current default branch. Historical tags, including `v0.2.10`, are not supported.

## Reporting a vulnerability

Do not report suspected vulnerabilities in public issues. Use [GitHub private vulnerability reporting](https://github.com/lars-hagen/mcp-playwright-cdp/security/advisories/new) and include reproduction steps, affected versions, and impact. If private reporting is unavailable, contact the maintainer through the repository owner profile.
